## Описание

**Атлас Леднёва** — интерактивный инструмент для специалистов по электроакупунктуре, сочетающий классическую диагностику по точкам с современными методами частотной терапии, цветотерапии и звуковой визуализации.

Приложение работает полностью офлайн, не требует сервера и сохраняет все данные в браузере пользователя. Оно объединяет пять независимых модулей:

1. **Атлас точек** — электроакупунктурные схемы по патологиям, диагностика КИП по Фоллю, история сеансов.
2. **Нозоды CAFL** — частотные наборы из базы *Consolidated Annotated Frequency List*, воспроизведение и запись WAV-файлов.
3. **Цветотерапия** — визуализация частотного ряда через октавное повышение до видимой части спектра.
4. **Микрофонный анализ** — живая визуализация звука, в том числе для практик с горловой чакрой.
5. **Аудиоплейлист** — анализ доминирующих частот музыкальных произведений в реальном времени.

## Основные модули

### 1. Атлас точек и диагностика КИП по Фоллю

- Отображает список патологий и относящиеся к ним точки акупунктуры.
- При клике на название точки открывается карточка с подробным описанием и изображением.
- Кнопка **«Добавить точку»** даёт возможность вносить в базу новые точки или редактировать существующие.
- Секундомер помогает контролировать время воздействия на точку.

**Диагностика КИП по Фоллю** — встроенный журнал измерений:
- Для каждой точки в карточке предусмотрены поля **«эледия»** и **«фоль»**.
- Значение поля «фоль» соответствует классической шкале КИП (0–100) и автоматически окрашивается по цветовому коду состояния точки:
  - 0–20: чёрный
  - 21–28: фиолетовый
  - 29–38: синий
  - 39–48: индиго
  - 49–65: зелёный (оптимальный диапазон)
  - 66–80: оранжевый
  - 81–100: красный
- После нажатия «save» значения фиксируются и не подлежат изменению.
- Записи группируются по пользователям, датам и патологиям, что позволяет отслеживать динамику состояния точек во времени.

### 2. Нозоды CAFL

Отдельная вкладка **«Нозод»** содержит базу частотных наборов из *Consolidated Annotated Frequency List* (CAFL, v2023). Каждый нозод отнесён к одной из категорий: растительные, витамины, микроэлементы, паразитарные, бактериальные, вирусные, грибковые, нозоды, гомеопатические препараты.

Для каждого набора доступны:
- **Воспроизведение** — одновременное звучание всех частот набора в стереорежиме с фазовым сдвигом 90° между каналами (левый канал отстаёт от правого на четверть периода). Это обеспечивает устойчивое ощущение объёмного звучания и корректное воспроизведение низких частот.
- **Запись WAV** — генерация аудиофайла в формате **32-bit PCM, стерео, 48 000 Гц (3072 кбит/с)**. Длительность задаётся пользователем от 1 до 600 секунд. Файл сохраняется в выбранную папку (в браузерах с поддержкой File System Access API) либо в папку загрузок. Имя формируется как `название_нозода_CALF.wav`.

### 3. Цветотерапия — визуализация частот через спектр света

Модуль **«Акустическо-Оптический Синтезатор»** переводит звуковые частоты в видимый спектр электромагнитных волн методом **октавного повышения**: длина волны звука приводится к диапазону 380–780 нм последовательным умножением на 2. Полученный цвет применяется к визуальным пятнам, движущимся по холсту.

Каждый набор частот превращается в самостоятельную свето-звуковую картину:
- **Скорость движения пятен** зависит от исходной частоты — высокие тона пульсируют быстрее.
- **Размер пятна** также масштабируется по частоте.
- **Режим наложения** (`screen`) складывает цвета пятен в пастельные и перламутровые оттенки, что позволяет создавать терапевтические палитры (золото, серебро, перламутр, радуга, колокол).

Встроенные пресеты: **Радуга, Золото, Серебро, Перламутр, Сольфеджио, Колокол** — а также наборы аккордов (C maj7, A min7, Dm, G мажор, Em, C aug, C dim, C квинта).

Параметр **«Делитель скорости бликования»** позволяет плавно изменять темп движения и пульсации пятен от 0.2× до 5.0× без потери звучания.

### 4. Микрофонный анализ — визуализация живого звука

Кнопка **🎤** активирует живой анализ с микрофона. Приложение в реальном времени выделяет до шести доминирующих пиков в диапазоне до 3000 Гц и строит по ним визуальную картину:

- Каждому пику соответствует пятно цвета, полученного через октавное преобразование частоты в длину волны видимого света.
- На верхней панели отображается **бегущая строка** с частотами и их HEX-кодами.
- В правой панели отображается список активных частот с длиной волны и их цветом.
- При тишине пятна плавно уходят в тёмный тон, экран остаётся живым за счёт частиц-блёсток.

**Практика для горловой чакры.** Микрофонный режим позволяет использовать визуализацию во время вокальных и дыхательных практик: пение мантр, длительное интонирование гласных («ОМ», «АУМ»), практики с Вишуддха-чакрой. Низкие вибрации голоса превращаются в медленные крупные пятна тёплых тонов, а высокие обертоны — в стремительные серебристо-голубые вспышки. Это делает визуальную обратную связь инструментом для работы с голосом, дыханием и эмоциональным состоянием.

### 5. Аудиоплейлист — анализ музыкальных произведений

Кнопка **🎵** позволяет загрузить один или несколько музыкальных файлов (MP3, WAV, OGG, M4A, FLAC и другие форматы, поддерживаемые браузером). Каждый файл проходит через анализатор спектра, и визуализация строится по **доминирующим частотам трека в реальном времени**:

- Пики спектра до 3000 Гц переводятся в цвета видимого диапазона.
- Пятна пульсируют в такт музыке, реагируя на изменения тембра, ритма и громкости.
- **Плейлист** хранится в памяти вкладки: можно добавлять треки, переключаться между ними, удалять отдельные записи или очищать очередь целиком.
- При завершении трека автоматически воспроизводится следующий.
- Кнопка **«Очистить»** останавливает воспроизведение и возвращает визуализацию к текстовому набору частот.

Музыкальный режим — это одновременно и инструмент пассивного сопровождения процедур, и наглядная демонстрация связи между гармонией звука и гармонией света.

## Импорт / Экспорт CSV

- Базовый набор точек загружается из файла `point.json`.
- Все добавленные или изменённые данные сохраняются в локальном хранилище браузера.
- Экспорт в CSV сохраняет все точки (базовые + пользовательские) для резервного копирования или переноса на другое устройство.
- Импорт из CSV позволяет восстановить данные или объединить их с текущими.

## Поиск и аналитика

- **Поиск по названию точки** — показывает все патологии, в которых встречается данная точка, что позволяет оценить её влияние на смежные системы организма.
- **Общие точки (суммационные пункты)** — выбор нескольких патологий показывает точки, общие для всех выбранных, что важно для комплексного лечения.

## История пользователя

- Возможность создавать нескольких пользователей и переключаться между ними.
- История сеансов группируется по датам (свёрнута по умолчанию), внутри — по патологиям.
- Для каждой точки можно ввести:
  - **Показания тестера Фолля** — значение КИП (см. раздел «Диагностика КИП по Фоллю»).
  - **Показания прибора Эледия** — параметры электроакупунктурного воздействия.
- После нажатия кнопки «save» значения фиксируются и не подлежат изменению.
- При клике на название точки открывается её карточка с полным описанием.

## Хранение данных

- Все пользовательские данные (точки, история, измерения) хранятся в `localStorage` браузера.
- Загруженные музыкальные файлы и текущий плейлист хранятся в оперативной памяти вкладки и очищаются при её закрытии.
- **Внимание:** очистка истории браузера может привести к потере данных. Рекомендуется регулярно экспортировать данные в CSV.
